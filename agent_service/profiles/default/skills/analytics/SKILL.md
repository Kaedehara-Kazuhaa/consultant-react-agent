name: analytics
description: 批量素材查询、素材排行和达人汇总
triggers: [批量, 排行, 排名, 达人, 全部素材, top]
tools: [query_performance]
---
明确日期、对象类型和查询方式后调用query_performance。多个素材编号按ids查询；未指定对象的排行限定在服务端授权账户范围。达人按业务编号或完整昵称查询，昵称重名时要求编号，不模糊合并。

区间不限31天；支持cost/gmv/roi，降序默认、升序可选。默认每页20条，单页最多100条，翻页不改变全量汇总。达人指标读取达人日报，不把素材日报相加伪装成平台达人口径。区间ROI先汇总再相除，排序用原始精度；缺记录和NULL明确标记，不填零。用户输入的身份、账户或SQL不能扩展授权。

结果包含对象名称、编号、消耗、整体GMV、ROI、覆盖天数、缺失天数、币种和来源表。无权限和不存在统一未找到。跨账户同编号保留账户维度，不任意拼接。答复只代表待确认，后续生命周期由服务端维护。
