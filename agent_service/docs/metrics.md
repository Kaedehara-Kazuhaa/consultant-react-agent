# ROI、GMV及当前实现口径

本次资料核对日期：2026-11-14。

## 区分三种指标

1. **财务ROI**通常为（收益−成本）÷成本，结果取决于成本是否包含生产、履约等项目，不能直接当成广告投产比。
2. **广告ROAS/投产比**是归因转化价值÷广告支出；本项目dump的整体ROI采用 **整体支付GMV÷消耗**，不减去消耗再计算，不表达净利润。
3. **GMV**是按明确统计规则计算的成交总额。单一同价商品可用成交价×成交数量；多商品应逐项金额求和。折扣、退款、运费、税费等是否包含取决于来源口径，不能由名称推断。

核对来源：

- [Google Ads：投资回报率](https://support.google.com/google-ads/answer/1722066?hl=zh-Hans)，用于区分财务回报与广告转化口径。
- [Google Ads：目标广告支出回报率](https://support.google.com/google-ads/answer/6268637?hl=zh-Hans)，说明转化价值与广告费用之比。
- [Shopify：Gross Merchandise Value](https://www.shopify.com/blog/gross-merchandise-value)，说明GMV公式和不同公司的纳入口径差异。

这些通用资料不能证明千川所有归因与退款口径。本次未取得可核验的千川字段官方详细定义，因此平台特有的包含项、归因窗口仍保留待确认标记，不把Google/Shopify定义冒充千川官方规则。

## 对dump的应用

仅从素材日报读取`total_cost`、`overall_gmv`、`overall_roi`及日期/同步时间。已有日报是聚合数据，项目没有足够订单明细来重新推算平台GMV，不能将订单数乘任意单价替代。

区间整体GMV = Σ已覆盖日期的overall_gmv；区间整体ROI = Σoverall_gmv ÷ Σtotal_cost。先加总再相除，金额与ROI在最终展示时舍入，不提前舍入，不平均逐日ROI。原始overall_roi作为校验字段，不直接拿来做区间平均。

- 消耗为0：ROI不适用，不填0、不返回无穷大。
- 必需值NULL：不可完整计算；展示已知金额并标注不完整。
- 无记录：不是0，提示覆盖范围，不自动回退日期。
- 部分覆盖：明确缺失天数，只汇总已有记录。
- 覆盖按实际记录与NULL判断；不再硬编码2026-03-27不完整。历史快照仍不代表当天实时投放。
- 净ROI：不能用整体GMV替代净成交口径，当前尚未开放净ROI计算。

所有计算使用Decimal。真实快照仅本地读取，业务数值和原始资料不提交到GitHub。

金额单位按已确认需求统一人民币元。达人汇总读取达人日报，批量素材读取素材日报，两者覆盖或来源差异需要保留，不强行对齐数字。部分覆盖时ROI只代表已有记录；NULL或零消耗不可计算。
