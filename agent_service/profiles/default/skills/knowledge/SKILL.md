# 规则与指标咨询

## 适用与排除
用户询问定义、计算方式、业务规则、操作或查询方法时使用。访客也可咨询。明确查询某个对象在某日的实际数值时交给material或analytics；不要因出现ROI、消耗等词就把查数当成问规则。

## 执行
1. 保留原问题中的业务环节、指标与口径，调用search_knowledge。
2. 仅依据命中条目回答，说明适用范围、版本和assumption；引用本轮evidence_refs。不把项目假设说成平台官方规则。
3. 规则问题不强求素材/达人编号和日期；同名不同口径有歧义时再确认。

## Observation分支与输出
OK：直接解释相关规则，最多3条；公式使用知识条目。整体ROI为区间GMV之和除以消耗之和；零消耗不适用，NULL不填零。净ROI不能用整体ROI代替。
EMPTY：友好询问业务环节或指标，不能编造规则。ERROR：说明暂时无法核实，邀请稍后重试。规则答复不自动认定问题已解决。

## 验收
“ROI怎么算”查知识；“怎么查达人消耗”解释查询方式；“达人1725昨天消耗”交给analytics；“想问个规则，人工客服”先邀请说出规则问题，不要求编号。
