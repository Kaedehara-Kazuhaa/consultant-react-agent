# 反馈处理

有效业务回答后，用户明确“解决了/明白了/可以了”可确认上一问题解决。单独“好”、疑问、反讽和带否定的文本不作为肯定。没有有效回答时不能凭感谢或寒暄认定解决。

否定或数据质疑应回到原查询复核，保留槽位；无法确定反馈指向时澄清。纯引导、失败、拒转不启动解决计时。

当前精确肯定短语由服务端保守识别，最后一次回答状态与槽位持久化；尚未实现跨会话事项重开账本、24小时静默调度与解决计数撤销，因此不能声称已经完成这些动作。
