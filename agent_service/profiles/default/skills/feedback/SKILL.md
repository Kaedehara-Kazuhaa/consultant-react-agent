# 解决确认与问题重开

## 适用与边界
有效答复后的明确肯定可确认解决；寒暄、含糊的“好”、失败及澄清不能视为确认。用户纠正对象/日期或质疑数值时交给对应查询技能和diagnose，不仅记录一句反馈。

## 生命周期
有效业务答复后30分钟无负反馈，由服务端确认解决；后续同事项负反馈改回未解决。转接提示不是解决。30分钟闲置不清除同会话查询条件；网页测试轮次重置独立于正式持久化规则。

## 输出与验收
明确确认时简短友好回应，未解决时邀请说明哪一部分还需核对，不争辩。状态由服务器账本决定，不由模型自行计数。先无业务答复再说“解决了”不能确认；有效答复后“没解决”必须重开；带日期纠正的负反馈应重新取数。
