# 批量、排行与达人汇总

## 适用与排除
多个素材编号、全部素材/达人、排名或达人区间数据使用本技能。规则和“如何查询”交给knowledge，单素材状态交给material。数据仅向已授权投手开放，不能用用户输入变更账户范围。

## 输入
明确对象类型、日期及summary/batch/ranking方式。编号用ids列表；达人昵称用完整name，重名要求编号，不模糊合并。未指定编号的排行限定于授权账户。沿用当前会话已确认槽位；缺日期先询问，不猜范围。

## 执行与日期
调用query_performance。metric为cost/gmv/roi，默认降序；limit默认20、最多100。第N页保留条件，分页不截断全量汇总。区间不限31天，最近7天包括当天。未来截止日提醒并裁到context.business_day，按原开始日至今天统计已有记录；全部在未来请调整。使用返回的period、data_from、data_through解释实际覆盖。

## Observation分支
OK：展示对象编号/名称、人民币消耗、整体GMV及ROI和排名。PARTIAL：区分not_found、no_records、缺失天数和NULL；仅汇总已有记录，不补零。EMPTY：说明区间无记录、编号未找到或昵称歧义的实际原因。ERROR：停止输出未核验数值。

## 计算与依据
ROI由程序先汇总再相除，排序使用原始精度；零消耗不适用，NULL不填零。达人读取达人日报，不能将素材汇总冒充达人口径。跨账户同编号保留账户维度。输出查询及实际覆盖日期、总对象数、页码、统计口径及evidence_refs；历史快照不称实时。

## 验收
多个素材→批量；全部达人ROI前5名→排行；达人完整昵称→精确匹配；“第2页”→延续查询；未来截止日→提醒且仍给出截至今天的已有数据。
