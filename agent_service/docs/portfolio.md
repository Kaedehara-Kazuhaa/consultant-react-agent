# 作品集运行与展示

## 当前方式
React前端由FastAPI在同一端口提供，默认仅监听127.0.0.1:8765。它适合本地开发、面试屏幕演示和评审者克隆运行；这是正常的前后端应用启动方式。无需为了作品集把项目改成纯静态网页。

GitHub仓库地址用于分享源码；本地端口地址不能让别人直接访问你的电脑。GitHub Pages只托管静态页面，不能直接运行这个Python后端，也不能安全存放模型密钥。公开演示需要额外的服务器/应用托管、HTTPS、服务器端密钥及访问控制；本项目当前没有提供公开托管地址。

## Windows克隆运行

准备Git、Python 3.12和Node.js 20.19+（或22.12+），然后运行：

```powershell
git clone https://github.com/Kaedehara-Kazuhaa/consultant-react-agent.git
cd consultant-react-agent
git checkout main
.\Setup.cmd
.\Start.cmd --data synthetic --provider demo --test
```

Setup.cmd只需在首次安装或依赖变化时运行；日常运行Start.cmd。安装过程需要网络，安装完成后demo决策器与合成数据可离线验证链路。该决策器不是语言模型，界面会明确标注。完整自然语言效果需要评审者自行配置兼容模型接口；密钥留在本地/服务器端，不在前端或仓库。

--test启用仅本机可用的网页测试身份选择器；每次刷新创建独立轮次，并支持访客/投手身份和历史频繁人工诉求场景。访客身份用于验证通用规则与业务查数权限的差异，不代表已实现生产登录。

## 建议演示顺序

1. 规则解释与知识依据。
2. 单素材日报、日期纠正及缺失/零/NULL差异。
3. 批量、达人汇总与排行分页。
4. 模糊诉求确认、负反馈与人工诉求的拦截/放行。
5. 查看具体技能、工具名称、输入参数、Observation和决策摘要，导出Trace。

建议用合成数据截图/录屏，不公开真实业务快照、对话日志或个人密钥；真实数据不是复现基础链路的必要依赖。项目能力以测试结果和实际工具范围为准，不宣称完整生产客服系统或100%意图识别。
