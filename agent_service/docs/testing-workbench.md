# 单次网页功能测试

本机已启用单次网页测试模式。运行 Start.cmd 后，每次打开或刷新网页都会创建独立测试身份；不会继承上轮的对话、查询条件、问题状态和转人工次数。业务快照不改变。

页面顶部可选择“已授权投手”或“访客（仅规则）”，也可勾选“预置历史频繁转人工用户”。身份或场景切换会重新开始测试。“重置本轮测试”清零当前轮次；“新对话”只更换会话，保留本轮客户的请求历史，用于跨会话限制测试。

关闭页面会尽力清理该测试身份的记录；浏览器强退、断网或正在执行请求时可能保留本地测试日志，但下次打开仍使用新身份，计数必定独立。测试令牌24小时失效，服务重启后失效。关闭时不会删除真实客户记录及业务数据。

|投手|查询达人999999999999在2026-03-24的消耗|当前可查询范围未找到，请核对编号/昵称|

|任意|不用转人工|不增加转人工请求次数|

测试轮次之间请点“重置本轮测试”或刷新。普通资格用户本会话默认第3次人工请求放行，与查数和有效尝试计数分开。新对话会按该客户此前其他会话的请求记录冻结历史资格；历史受限场景仍继续引导。

## 权限与语义边界

测试身份选择器仅在显式启用 AGENT_TEST_MODE=1 且本机访问时可用；当前电脑使用忽略提交的 var/model.local.json 启用。正式身份应由认证系统注入，不能信任用户在消息中自称投手。业务数据还受品牌与账户范围约束。

明确的转人工表达由服务端识别，否定表达及规则询问单独处理。开放自然语言不能承诺100%识别；新增说法应纳入回归用例。模型负责业务理解与答复，不能修改转人工资格和数据权限。

模糊进线由程序提供带上次对象及日期的候选约束，真实模型负责组织确认话术。没有上次业务查询时继续检查可用后台上下文；没有依据时仅引导补充。

## 未来日期与执行轨迹

截止日晚于对话当天时先提示范围可能有误，再给出原开始日至今天的已有数据，注明最新日报日期；整个区间都在未来则请调整开始日。不会把未来日期作为缺失日报，也不会擅自把今天改成快照最后一天。

右侧折叠项直接显示技能中文名称及标识（如knowledge）、具体工具（如search_knowledge）；展开后查看版本、参数和返回值。新电脑可运行Start.cmd --data synthetic --provider demo --test直接开启测试工作台。
