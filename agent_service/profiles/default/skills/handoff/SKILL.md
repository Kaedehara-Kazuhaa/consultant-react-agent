triggers: [转人工]

转人工由服务端策略执行，不依赖模型选择工具。请求事件以request_id去重持久化，按用户+品牌隔离；会话开始时冻结前30天、其他会话的历史请求数，达到3次限制本会话普通转接。该30天/3次历史阈值为待确认默认参数。

纯转人工请求优先引导用户说明问题、补充对象日期、指出未解决部分。三次不同的有效推进后，历史资格允许则输出“正在为您转接。”并标记HANDOFF_PENDING。相同答复重复查询、故障重试不增加有效次数。混合业务请求先查数，不直接转接。本期只输出提示，未对接人工系统，不声称接通或派单成功。
