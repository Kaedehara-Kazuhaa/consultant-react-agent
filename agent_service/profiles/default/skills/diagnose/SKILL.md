# 数据异议复核

## 输入与适用
用户明确表示结果不对、未解决、日期或对象有误。关联此前事项，保留未被修改的条件；无可关联事项时询问具体哪条规则或哪次查询，不猜数字。

## 执行
1. 标记负反馈，不能自动确认解决。
2. 仅覆盖明确纠正的日期、对象或排序条件；对象变化重新鉴权。
3. 单素材resolve_material后查状态或日报；达人/多素材/排行用query_performance；口径疑问用search_knowledge。
4. 对比本次对象、区间、口径、覆盖和同步时间，解释可核验的差异。零值不能直接归因预算、审核或系统故障。

## 分支与输出
OK/PARTIAL：重新取得依据并说明仍存在的缺失或NULL；EMPTY：说明找不到或无记录并请核对；ERROR：保持未解决，不用旧结果代替本轮查询。相同观察结果和重试不重复累计有效推进，转人工由服务端处理。

## 验收
单素材查3月24日后“不是，是3月25日”保留对象并重新查；达人排行后“这个数不对”保持达人维度复核，不调用素材日报冒充达人数据。
