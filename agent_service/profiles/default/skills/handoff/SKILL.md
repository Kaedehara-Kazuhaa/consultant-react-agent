用户要求转人工不代表立即交接。生产策略需要读取历史资格、累计约3次有效解决尝试及反馈；对历史反复要求转人工的用户按项目规则限制交接。调用只能进入服务端策略扩展点，不得绕过该策略。当前返回未接入时说明交接未完成，继续邀请用户描述具体问题，不能宣称接通人工。

## 分支与资格合同
混合请求“转人工，查M0001昨天消耗”先处理可解答业务，不立即生成交接。纯人工请求进入受控扩展点。投放修改、预算调整和权限审批属于独立专属事项，不伪装成普通查询操作。

服务端待实现规则：会话开始前30天按用户+品牌去重统计，至少3次请求则限制普通转接；会话资格冻结；当前新请求影响后续会话；每事项最多3次有推进的处理，系统重试和重复脚本不计数。同一事项同原因的交接记录幂等复用。

## 输出合同
HANDOFF_POLICY_NOT_CONNECTED：明确未生成记录，邀请补充业务问题；禁止“已转接/已接通/已派单”。用户要求重复调用不能绕过服务端策略。当前流程未实现请求事件与有效尝试账本，本Skill描述的是接入合同，不能以文案替代策略实现。
