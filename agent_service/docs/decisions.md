# 当前业务规则与待确认参数

本页是实现约定清单。已确认需求与临时默认分开，避免把实现便利当成业务要求。更新日期：2026-11-15。

## 已确认并实现

- 业务页面优先读取dump只读快照；合成数据保留为测试夹具，不混入dump查询结果。
- 单素材、批量素材、素材排行、达人汇总与达人排行；区间不限制31天。
- 最近7天包含对话当天和此前6天。相对日期按上海时区对话当天换算，金额人民币元。
- 同一会话闲置超过30分钟仍保留对象、日期等槽位；新问题的明确条件优先，不把旧条件无差别带入新话题。
- 有效业务答复后30分钟没有同事项负反馈，确认解决；明确肯定可提前确认。后续同事项负反馈撤销解决认定，状态为未解决，不在同轮因重新查数再次算解决。
- 人工请求持久化、去重并隔离用户和品牌；优先解决问题，约3次有效推进后资格允许则输出“正在为您转接。”，状态HANDOFF_PENDING，不等同于已解决。
- 本次不对接人工系统，不调用外部转接接口。

## 数据与状态边界

达人汇总读取influencer_daily_trend_cache；素材读取material_daily_trend_cache。不同报表的覆盖与同步可能不同，不能假定两种汇总总额必然相等。无记录和NULL不补零，部分覆盖的ROI只代表已有记录；净ROI仍未开放。移除旧的“2026-03-27必然不完整”硬编码，按实际日期覆盖和NULL判断；当前无法证明平台每一天已完成最终结算。

人工历史从本项目持久化的请求事件开始累计，没有将dump原对话不加身份核验地导入当前用户。当前身份仍是本地快照查看身份；正式多客户登录、外部人工系统、用户行为平台、跨会话同事项语义关联待接入；DeepSeek Flash已接通，真实模型效果仍需扩充评测。状态账本会记录静默确认、显式确认和负反馈事件；状态账本与Trace可用于复核，不把工具运行成功等同于真实解决率。

前端使用标签页会话并保留消息，刷新不丢槽位；点击“新对话”创建新的会话，旧记录留在本地运行库。人工历史依然跨会话统计，不能通过新对话清除历史限制。合成测试与实际业务数据分别存储运行库。

## 单次网页测试模式

本机测试使用独立随机客户身份隔离每次页面生命周期，保留轮内多会话历史；刷新和身份切换创建新轮次。服务端提供访客/投手权限和历史频繁用户夹具，不增加登录系统。生产模式继续使用部署身份及持久化账本。详见 [测试工作台](testing-workbench.md)。
